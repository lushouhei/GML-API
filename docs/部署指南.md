# GML-API 部署指南（零基础版）

> 这份文档假设你**一行代码都不会写**。照着做就行，每一步都告诉你「做什么」和「为什么」。
> 全程大约 20-30 分钟，其中一半时间在等 Cloudflare 注册。

---

## 这玩意儿到底是干嘛的？

你有智谱清言（chatglm.cn）的**网页会员**。会员只能在网页上聊天，没法给别的软件用。

这个项目在 Cloudflare 上开一个「中转站」：
- 你的软件（Cherry Studio、NextChat、Claude Code 等）以为自己在调 OpenAI 的 API
- 中转站收到请求后，伪装成浏览器去调智谱网页版的私有接口
- 把智谱返回的内容翻译成 OpenAI 格式返回给你的软件

**结果**：你的网页会员变成了一个能给任何软件用的 API，且不花额外的钱。

## 第 1 步：拿到你的智谱钥匙（refresh_token）

这是整个项目的**命根子** —— 中转站靠它冒充你登录。

1. Chrome 打开 https://chatglm.cn ，**登录你的会员账号**
2. 按 `F12` 打开开发者工具
3. 点顶部的 **Application**（中文版叫「应用」）
4. 左侧找到 **Storage → Cookies → https://chatglm.cn**
5. 在右边的列表里找到名字是 `chatglm_refresh_token` 的那一行
6. **双击它的 Value 那一格**，全选（Ctrl+A）、复制（Ctrl+C）

> 这个值很长，以 `eyJhbGci...` 开头，是一段 JWT。
> ⚠️ **它等于你的账号钥匙**。泄露出去别人就能白嫖你的会员，千万别发群里、别传 GitHub。

### 把它存进配置文件

在项目目录打开 PowerShell，运行：

```bash
Copy-Item config\token.txt.example config\token.txt
notepad config\token.txt
```

把最后一行的示例值替换成你刚复制的真实 token，保存关闭。

## 第 2 步：体检 —— 先确认这条路还通

**别急着部署。** 智谱随时可能改接口，先花 10 秒验证一下，省得白忙一场。

```bash
python scripts\check_token.py
```

看到 `[OK] token 有效！` 就继续往下。

看到 `[X] refresh_token 已过期` → 回第 1 步重新复制。
看到 `[X] 返回的不是 JSON，接口可能已改版` → 智谱改协议了，这个项目暂时用不了，**停在这里别往下走**。

---

## 第 3 步：注册 Cloudflare 并登录命令行

1. 打开 https://dash.cloudflare.com/sign-up ，用邮箱注册（免费版够用）
2. 去邮箱点验证链接
3. 回到 PowerShell，在项目目录运行：

```bash
npx wrangler login
```

会自动弹出浏览器让你授权，点 **Allow** 即可。终端显示 `Successfully logged in` 就成功了。

---

## 第 4 步：创建 KV 存储（放你的 token 的柜子）

KV 是 Cloudflare 的一个小型数据库，用来存你的 token 和 API Key。

```bash
npx wrangler kv namespace create GLM_TOKENS
```

命令会输出类似这样一段：

```
[[kv_namespaces]]
binding = "GLM_TOKENS"
id = "a1b2c3d4e5f6a7b8c9d0e1f2a3b4c5d6"
```

**把那串 id 复制下来**，下一步要用。

---

## 第 5 步：填配置文件

先复制一份配置模板到项目根目录：

```bash
Copy-Item config\wrangler.toml.example wrangler.toml
```

生成一个管理密钥（用来保护管理接口不被陌生人调用）：

```bash
[guid]::NewGuid().ToString("N")
```

打开配置文件填两个地方：

```bash
notepad wrangler.toml
```

- `ADMIN_KEY = "把这里换成上面生成的随机字符串"` → 换成刚生成的那串
- `id = ""` → 填入第 4 步拿到的 KV id

保存关闭。

> 💡 这个文件已经被 `.gitignore` 排除，不会被传到 GitHub 上。

---

## 第 6 步：一键部署

```bash
powershell -ExecutionPolicy Bypass -File scripts\deploy.ps1
```

脚本会先帮你检查配置有没有填错，然后自动安装依赖并部署。

成功后终端会打印一个网址，类似：

```
https://glm-2api.你的用户名.workers.dev
```

**把这个网址记下来**，下一步要用。

---

## 第 7 步：灌钥匙 + 实测

```bash
powershell -ExecutionPolicy Bypass -File scripts\setup_keys.ps1
```

脚本会：
1. 把你的智谱 token 推进中转站的 Token 池
2. 自动生成一个 API Key（就是你以后在各种软件里填的那个 key）
3. **实测发一句话**，确认整条链路真的通
4. 把结果保存到 `config/secrets.txt`

看到 `[OK] 模型回复: 收到` —— 大功告成 🎉

---

## 第 8 步：在软件里用起来

打开 `config\secrets.txt`，里面有你的接口地址和 API Key。

### Cherry Studio / NextChat / LobeChat（推荐，最省事）

添加自定义模型服务商，选 **OpenAI 兼容**：

| 填什么 | 填什么值 |
|---|---|
| API 地址 / Base URL | `https://你的域名/v1` |
| API Key | `sk-glm-xxxxx`（secrets.txt 里那个） |
| 模型名称 | `glm-4.7` |

### Python 代码调用

```python
from openai import OpenAI

client = OpenAI(
    api_key="sk-glm-你的key",              # secrets.txt 里的 API Key
    base_url="https://你的域名/v1"          # 注意结尾有 /v1
)

resp = client.chat.completions.create(
    model="glm-4.7",
    messages=[{"role": "user", "content": "你好"}],
)
print(resp.choices[0].message.content)
```

### 管理面板

浏览器打开 `https://你的域名/admin`，输入 ADMIN_KEY 就能可视化管理 token 和 API Key，不用敲命令。

## 常见问题排错

### Q1：大陆访问 workers.dev 打不开 / 连接被重置

`.workers.dev` 域名在大陆常被拦截。两个方案：

- **方案 A（推荐）**：买个便宜域名（阿里云/腾讯云约 10 元/年），把 NS 转到 Cloudflare，然后在 Worker 设置 → Triggers → Custom Domains 绑定 `api.你的域名.com`
- **方案 B**：只在开代理的情况下使用

### Q2：报错「refresh_token 已过期」

智谱的 token 有有效期。重新执行第 1 步复制新 token，然后：

```bash
python scripts\check_token.py           # 先验证新 token
powershell -File scripts\setup_keys.ps1 # 再重新灌进去
```

也可以直接在 `https://你的域名/admin` 管理面板里替换，更快。

### Q3：报错 `No refresh tokens available in pool`

Token 池是空的，说明第 7 步没执行成功。重跑 `setup_keys.ps1`。

### Q4：报错 401 Unauthorized

- 调 `/v1/chat/completions` 时报 401 → API Key 填错了，对照 `config/secrets.txt`
- 调 `/admin/*` 时报 401 → ADMIN_KEY 填错了

### Q5：模型名到底填什么？

**随便填**。看 `src/chat.ts` 的源码，模型名只在两种情况下起作用：

- 填 24 位以上的纯字母数字 → 当成智谱「智能体 ID」使用（比如指定某个绘图智能体）
- 名字里含 `think` / `zero` → 开启深度思考模式；含 `deepresearch` → 开启深度研究模式

其余情况一律走智谱网页版的默认助手。所以 `glm-4.7`、`glm5`、`gpt-4` 填哪个都是同一个模型。

### Q6：工具调用（Function Calling）不稳定

这是**设计上的固有限制**，不是 bug。智谱网页版接口本身不支持工具调用，本项目是用「在 system 提示词里教模型输出 JSON + 后处理解析」硬凑出来的。复杂嵌套参数容易解析失败。

拿它跑 Claude Code 这类重度依赖工具调用的场景，**预期会不稳**。

## 风险提醒（务必看完）

1. **违反服务条款**：把网页会话封装成 API 属于非官方用法，智谱有权风控或封禁账号。仅建议个人自用。
2. **别高频跑**：网页版有速率限制，短时间大量请求容易触发风控。别拿它跑批量任务。
3. **别对外提供服务**：分享给别人用 = 你的账号替别人背锅。
4. **token 会失效**：智谱改接口、换签名算法，这个项目随时可能失效。上游作者更新也不频繁（1 star 的小项目）。
5. **官方替代方案**：如果要稳定生产可用，用 https://open.bigmodel.cn/ 的官方 API，按量付费，有 SLA 保障。
